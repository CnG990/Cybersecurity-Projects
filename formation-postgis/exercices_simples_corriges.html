Exercice 3. Vrai ou faux ?
a) Le SRID 4326 donne des coordonnées en mètres.
b) Malicounda Est est dans la zone UTM 28 Nord.

e) Vrai.

a) zone tampon (ST_Buffer) · b) emprise (ST_Extent) · c) centroïde (ST_Centroid) · d) intersection (ST_Intersection)

Série 2

Les types de données

Dans pgAdmin · 20 min

Rappel

INTEGER (entier), NUMERIC (nombre à virgule, avec un point), VARCHAR (texte entre guillemets simples), DATE ('AAAA-MM-JJ'), BOOLEAN (TRUE / FALSE).

Exercice 5. Afficher le texte Malicounda Est dans une colonne nommée lotissement.
Correction
SELECT 'Malicounda Est' AS lotissement;
lotissement
Malicounda Est
Exercice 6. Calculer la surface d'un lot de 20 m sur 15 m.
Correction
SELECT 20 * 15 AS surface_m2;
surface_m2
300
Exercice 7. Calculer 9 / 2 puis 9.0 / 2. Pourquoi les résultats sont-ils différents ?
Correction
SELECT 9 / 2 AS a, 9.0 / 2 AS b;
ab
44.5

Entre deux entiers, la division est entière : 9 / 2 = 4. Avec 9.0, le calcul est décimal : 4,5.

Exercice 8. La table compte 3 120 lots, dont 2 340 ont un propriétaire. Calculer en SQL le nombre de lots sans propriétaire.
Correction
SELECT 3120 - 2340 AS lots_sans_proprietaire;
lots_sans_proprietaire
780

a) VARCHAR (il contient des lettres) · b) NUMERIC · c) DATE · d) BOOLEAN · e) INTEGER

Série 5

Les géométries simples

Dans pgAdmin · 25 min

Rappel

ST_GeomFromText('POINT(x y)', srid) fabrique une géométrie. Sans SRID, les exemples sont dans un repère simple en mètres. Un polygone se ferme en répétant le premier point.

Exercice 22. Fabriquer le point de coordonnées X = 288950, Y = 1598260 en SRID 32628, et l'afficher en texte.
Correction
SELECT ST_AsText( ST_GeomFromText('POINT(288950 1598260)', 32628) );
st_astext
POINT(288950 1598260)
Exercice 23. Un terrain rectangulaire mesure 20 m sur 25 m. Écrire son polygone (coin en 0 0), puis calculer sa surface et son périmètre.
Correction
SELECT ST_Area(     ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))')) AS surface,
       ST_Perimeter(ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))')) AS perimetre;
surfaceperimetre
50090

20 × 25 = 500 m² ; 2 × (20 + 25) = 90 m.

Exercice 24. Quelle est la longueur de la ligne qui va du point (0 0) au point (30 40) ? Quel est son type ?
Correction
SELECT ST_Length(ST_GeomFromText('LINESTRING(0 0, 30 40)'))  AS longueur,
       GeometryType(ST_GeomFromText('LINESTRING(0 0, 30 40)')) AS type;
longueurtype
50LINESTRING
Exercice 25. Trouver le centre (centroïde) du terrain de 20 m × 25 m.
Correction
SELECT ST_AsText( ST_Centroid( ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))') ) );
st_astext
POINT(10 12.5)
Exercice 26. Le point (5 5) est-il dans le terrain de 20 m × 25 m ? Et le point (50 5) ?
Correction
SELECT ST_Contains(ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))'),
                   ST_GeomFromText('POINT(5 5)'))  AS point_5_5,
       ST_Contains(ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))'),
                   ST_GeomFromText('POINT(50 5)')) AS point_50_5;
point_5_5point_50_5
truefalse
Exercice 27. Convertir le point X = 288950, Y = 1598260 (SRID 32628) en coordonnées GPS (SRID 4326).
Correction
SELECT ST_AsText( ST_Transform( ST_GeomFromText('POINT(288950 1598260)', 32628), 4326) );
st_astext
POINT(-16.957857 14.448780)

Longitude -16,9579, latitude 14,4488 : on est à Malicounda Est.

Série 6

Les fonctions ST_ sur les vrais lots

Dans pgAdmin · 30 min

Rappel

La colonne géométrique de la table s'appelle wkb_geometry. Pour comparer deux lots, on cite la table deux fois avec deux surnoms : FROM "malicouda est" a, "malicouda est" b.

Exercice 28. Pour le lot 3708 : afficher le type de géométrie, le SRID, la surface et le périmètre (arrondis).
Correction
SELECT GeometryType(wkb_geometry)        AS type,
       ST_SRID(wkb_geometry)             AS srid,
       ROUND(ST_Area(wkb_geometry))      AS surface,
       ROUND(ST_Perimeter(wkb_geometry)) AS perimetre
FROM "malicouda est"
WHERE "n° du lot" = '3708';
typesridsurfaceperimetre
MULTIPOLYGON3262830070
Exercice 29. Les lots 3708 et 3709 se touchent-ils ? Quelle distance les sépare ?
Correction
SELECT ST_Touches (a.wkb_geometry, b.wkb_geometry) AS se_touchent,
       ST_Distance(a.wkb_geometry, b.wkb_geometry) AS distance
FROM "malicouda est" a, "malicouda est" b
WHERE a."n° du lot" = '3708' AND b."n° du lot" = '3709';
se_touchentdistance
true0

Ils sont voisins : distance 0.

Exercice 30. Même question pour les lots 3708 et 2944.
Correction
SELECT ST_Touches(a.wkb_geometry, b.wkb_geometry) AS se_touchent,
       ROUND(ST_Distance(a.wkb_geometry, b.wkb_geometry)::numeric, 1) AS distance_m
FROM "malicouda est" a, "malicouda est" b
WHERE a."n° du lot" = '3708' AND b."n° du lot" = '2944';
se_touchentdistance_m
false273.8
Exercice 31. Donner les coordonnées GPS du centre du lot 3708.
Correction
SELECT ST_AsText( ST_Transform( ST_Centroid(wkb_geometry), 4326) )
FROM "malicouda est"
WHERE "n° du lot" = '3708';
st_astext
POINT(-16.957881 14.448871)
Exercice 32. Dans quel lot se trouve le point X = 288950, Y = 1598260 (SRID 32628) ?
Correction
SELECT "n° du lot"
FROM "malicouda est"
WHERE ST_Contains(wkb_geometry, ST_GeomFromText('POINT(288950 1598260)', 32628));
n° du lot
3710
Exercice 33. Combien de lots ont une géométrie invalide ?
Correction
SELECT COUNT(*) FROM "malicouda est" WHERE NOT ST_IsValid(wkb_geometry);

Série 7

Trouver l'erreur

Sur papier, puis vérifier dans pgAdmin · 20 min

Exercice 34. Cette requête renvoie une erreur. Pourquoi ? Corriger.
SELECT superficie FROM malicouda est;
Correction

Erreur : relation "malicouda" does not exist. Le nom contient un espace : il faut des guillemets doubles.

SELECT superficie FROM "malicouda est";
Exercice 35. Cette requête renvoie une erreur. Pourquoi ? Corriger.
SELECT * FROM "malicouda est" WHERE "n° du lot" = "3710";
Correction

Erreur : column "3710" does not exist. Entre guillemets doubles, PostgreSQL croit que 3710 est un nom de colonne. Une valeur s'écrit entre guillemets simples.

SELECT * FROM "malicouda est" WHERE "n° du lot" = '3710';
Exercice 36. Cette requête répond 0. Pourtant, 257 lots n'ont pas de numéro. Pourquoi ? Corriger.
SELECT COUNT(*) FROM "malicouda est" WHERE "n° du lot" = NULL;
Correction

NULL veut dire « inconnu » : rien n'est jamais « égal » à une valeur inconnue. On écrit IS NULL.

SELECT COUNT(*) FROM "malicouda est" WHERE "n° du lot" IS NULL;   -- 257
Exercice 37. Ce polygone est refusé. Pourquoi ? Corriger.
SELECT ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25))');
Correction

Erreur : geometry contains non-closed rings. Le contour n'est pas fermé : il faut répéter le premier point à la fin.

SELECT ST_GeomFromText('POLYGON((0 0, 20 0, 20 25, 0 25, 0 0))');
Exercice 38. Pour retrouver le lot d'un point GPS (latitude 14,4487, longitude -16,9579), un étudiant écrit la requête ci-dessous. Elle ne trouve aucun lot. Pourquoi ? Corriger.
SELECT "n° du lot" FROM "malicouda est"
WHERE ST_Contains(wkb_geometry,
      ST_Transform(ST_SetSRID(ST_MakePoint(14.4487, -16.9579), 4326), 32628));
Correction

ST_MakePoint attend X puis Y, donc longitude puis latitude. Ici les deux sont inversés : le point part dans le sud de l'Angola.

SELECT "n° du lot" FROM "malicouda est"
WHERE ST_Contains(wkb_geometry,
      ST_Transform(ST_SetSRID(ST_MakePoint(-16.9579, 14.4487), 4326), 32628));
n° du lot
3710
Exercice 39. Un étudiant veut la surface du lot 3710 et obtient 0.000000025. Pourquoi ? Corriger.
SELECT ST_Area( ST_Transform(wkb_geometry, 4326) )
FROM "malicouda est" WHERE "n° du lot" = '3710';
Correction

En SRID 4326, les coordonnées sont en degrés : la surface sort en « degrés carrés », sans signification. On mesure dans le SRID d'origine, 32628, en mètres.

SELECT ST_Area(wkb_geometry)
FROM "malicouda est" WHERE "n° du lot" = '3710';      -- 300
